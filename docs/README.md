## Hosting

GitHub Pages serves the `docs/` directory on the `main` branch. `.nojekyll` disables
Jekyll processing. The site uses static HTML and CSS with no client scripts,
analytics, external fonts, or private installation data.

The application implementation and its private configuration are maintained
outside this directory. Publishing this website does not publish the coupon spreadsheet.
