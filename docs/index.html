Your offers,
in one place.

MyCoupons helps its owner collect coupon codes, discounts and vouchers from Gmail into a private Google Sheet.

This is a private project currently being implemented and configured. It is not open for public registration. This website provides application and privacy information; it does not display email or coupon data.

How it works

  1. Read the offer. Inspect email text and images for coupon codes, discounts, expiry dates and conditions.
  2. Keep a useful record. Save offers and links to their source emails in the owner's Google Sheet.
  3. Review uncertain details. Flag incomplete information so the owner can check the original email before confirming it.

Why Google account access is needed

Gmail access allows the importer to inspect messages and images and to label and archive messages after a confirmed import. Sheets access stores offers and review decisions. Drive access identifies and checks the destination spreadsheet. Scheduled Apps Script executions run the workflow and send relevant summaries to the owner.

When AI extraction is needed, email text and images are sent to Google's Gemini API or the configured Vertex AI backend. Downloading remotely hosted email images can reveal to the sender that an image was requested. These data flows are described in the privacy policy.
