# Third-party source

## HTML parser

`src/vendor/Html.gs` bundles [parse5 7.3.0](https://github.com/inikulin/parse5/tree/v7.3.0)
and its character-reference dependency [entities 6.0.1](https://github.com/fb55/entities/tree/v6.0.1).
The adjacent `LICENSE-parse5.txt` (MIT) and `LICENSE-entities.txt` (BSD-2-Clause)
preserve their complete license notices. `package-lock.json` pins the distributed
packages and integrity hashes. Upstream sources are not patched.

The bundle exports only `MC_HTML.parse`. Parsed text and attributes
already have context-correct character references; never decode them again.
MyCoupons parses each input as an HTML document with scripting disabled and
extracts content from ordinary child nodes, excluding comments, non-content containers, inert template contents and HTML
`hidden` subtrees. Foreign SVG/MathML subtrees are excluded from evidence and
mark coverage incomplete, including when nested inside suppressed containers.
Candidate consumers retain this coverage through raw HTML input. This is content
extraction without CSS layout or visibility evaluation. Document parsing retains `html`/`body` attributes; ordinary snippets
receive implicit wrappers. Leading document whitespace and orphan table tags
follow standard document rules; no fragment container context is guessed.
No scripts execute and no external resources are loaded.

The 7.3.0 pin runs without Node, DOM or browser globals in Apps Script's V8-style
environment. The evaluated 8.0.1 / entities 8 bundle requires `atob`, which is not
part of that runtime contract. Compatibility is checked against the committed
artifact in an empty VM and both application source-loading orders. Actual
Apps Script deployment is a later implementation increment.

All 2,231 WHATWG named references passed through both parsed text and attributes
of the committed bundle on 2026-09-07. Normal tests also cover numeric references,
single decoding and references split across removed markup.

## Reproduction and upgrades

Normal `npm test` and `npm run check` use the committed artifact offline.
The checker validates its SHA-256 and both license checksums. Rebuilding requires
Node.js 22+, npm 10+ and the locked build dependencies:

```sh
npm ci --ignore-scripts
npm run build:html
npm run check:html-build
```

`scripts/html-entry.mjs` selects the exported API; `scripts/build-html.mjs` uses
the pinned `esbuild-wasm` tool to produce a standalone ES2020 IIFE and copy the
licenses. `check:html-build` compares generated bytes without changing files.
The build tool runs locally only and is not included in the Apps Script bundle.

For upgrades, review upstream changes, update package pins and lockfile, rebuild,
and update the checksums in `scripts/check.mjs`. Verify a byte-identical rebuild
and repeat malformed HTML, text/attribute entity-context and empty-VM tests.
Compare every entry of the [WHATWG character-reference table](https://html.spec.whatwg.org/entities.json)
through parsed text inside a `<p>` container and parsed attributes, then run normal
validation. Do not substitute
a Node-only import for tests of the actual deployed bundle.
