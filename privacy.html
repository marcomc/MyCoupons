MyCoupons

Privacy policy

Last updated: 7 September 2026

MyCoupons is a personal Gmail-to-Google-Sheets coupon manager operated by Marco Massari Calderone. It is currently being implemented and configured for its owner; there is no public registration. This policy describes the application's data flows when it is authorized and enabled.

Information accessed

The importer accesses messages within its configured processing period, whether read or unread. This includes message identifiers, dates, subjects, sender information, plain text and HTML bodies, supported attached and inline images, and remote image links. Reading messages to identify offers can also expose information unrelated to a coupon.

It accesses spreadsheet content and Drive file metadata to identify the destination, check access, preserve existing records, avoid duplicates and recover processing progress. It checks the authenticated account's email address against the configured owner.

How information is used

Information is used to identify coupons, automatic discounts and vouchers; preserve conditions and expiry information; create and update spreadsheet records; handle review decisions; prevent duplicate processing; recover interrupted work; and send import, review or error summaries to the owner.

After a successful confirmed import, MyCoupons applies its configured Gmail label and removes the source message from the inbox. It does not intentionally change read/unread state or delete source messages. Review and ignored items follow the owner's decisions.

MyCoupons does not sell Google account data, use it for advertising, build marketing profiles or use it to train its own machine-learning models. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

AI processing and other recipients

When AI extraction is needed, bounded email text, links, the email date and selected images are sent to Google through the Gemini Developer API. If configured, requests may use Vertex AI instead, including a temporary paid fallback after a qualifying primary-backend quota response. These inputs may contain personal information present in the email. AI output is used to propose coupon records.

Google's processing, retention and use of API inputs and outputs depend on the selected service, account, region and applicable terms. See the Gemini API terms, Google Cloud Privacy Notice and Google Privacy Policy. MyCoupons does not promise zero retention by these providers.

If remote image fetching is enabled, MyCoupons requests selected image URLs from their hosting servers. A unique image URL can allow the sender or image provider to associate that request with the recipient. Recognizable tracking images are filtered, but this cannot guarantee that every tracking mechanism is detected.

Coupon records and summaries remain in the owner's Google services. MyCoupons does not publish the destination spreadsheet, expose a public coupon API, or send these records to advertisers or other users.

Storage and protection

Offers and source-email links are stored in the owner's Google Sheet. A hidden technical tab stores message identifiers, extracted candidates, processing states and notification progress. Hidden tabs are organizational aids, not separate access controls: anyone given access to the spreadsheet could access them.

Configuration, processing cursors and the Gemini API key are held in Apps Script Properties. Installation may use a private Google Cloud Secret Manager resource to transfer configuration. Owner-managed CLI credentials remain in local authentication storage. Access depends on Google account, project and file permissions; the intended installation grants access only to its owner.

The importer processes email text and image bytes during execution. It does not intentionally write full raw messages or image files to a separate archive. Extracted records, notes and summaries can retain excerpts from messages. Google services may retain operational or security logs under their own terms.

Retention, deletion and control

Coupon records and the processing journal remain until the owner removes them. Summary emails remain subject to the owner's Gmail retention and deletion choices. There is no automatic retention period for the spreadsheet journal in this version.

The owner can stop scheduled processing, disable remote image fetching, change AI configuration, or revoke the application's access from Google Account connections. Revoking access stops further authorized API access but does not remove existing spreadsheet records or emails.

To remove application data, first stop processing, then remove the coupon records and technical journal, the Apps Script configuration and project, and any installation credentials or secrets that are no longer needed. Deleting journal entries while the importer remains enabled can cause older messages to be processed again. Deletion from Google's backups and service logs is governed by Google's policies.

This information website

These application pages are hosted by GitHub Pages. They do not contain sign-in forms, analytics, advertising scripts or embedded third-party assets, and do not access the coupon spreadsheet. GitHub may process ordinary connection information, such as IP addresses and request logs, to deliver and protect the website. See the GitHub General Privacy Statement.
